### LocalLens AI

Local PDF search and retrieval system that lets users upload PDFs, search extracted text, retrieve relevant passages, generate summaries, and create quiz-style questions without paid AI APIs.

<p>
  <img src="https://img.shields.io/badge/React-20232A?style=flat-square&logo=react&logoColor=61DAFB" alt="React" />
  <img src="https://img.shields.io/badge/Node.js-339933?style=flat-square&logo=nodedotjs&logoColor=white" alt="Node.js" />
  <img src="https://img.shields.io/badge/Express-000000?style=flat-square&logo=express&logoColor=white" alt="Express" />
  <img src="https://img.shields.io/badge/JavaScript-F7DF1E?style=flat-square&logo=javascript&logoColor=000000" alt="JavaScript" />
  <img src="https://img.shields.io/badge/PDF%20Parsing-B30B00?style=flat-square&logo=adobeacrobatreader&logoColor=white" alt="PDF Parsing" />
</p>

- Local document search with PDF upload and parsing
- Document chunking for retrieval
- Extractive passage search with citation/source-style references
- Summary and quiz-style question generation
- TF-IDF/BM25-style ranking approach
- No OpenAI, Anthropic, or Gemini API dependency
